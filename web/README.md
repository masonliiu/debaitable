# DebAItable Web

This folder is reserved for the frontend app.

Recommended layout:
- `web/src` for frontend source code
- `web/public` for static assets
- `web/dist` for built web assets (do not commit)

You can initialize any frontend stack here, for example:
- Vite + React
- Next.js

Root scripts already support:
- `npm run dev:web`
- `npm run build:web`
